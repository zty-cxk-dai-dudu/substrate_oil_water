Usage

Extract the ZIP and open the substrate_oil_water directory. The analysis scripts use Python 3.11 or later.

python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt

For example, convert the CaF₂ AIMD model to CIF:

python analysis/structures/export_cif.py input_files/aimd/cafyoushui/H2O/POSCAR caf2_model.cif --format vasp

The README describes input formats, dependencies and commands for VDOS, hydrogen-bond and interaction-energy calculations.
